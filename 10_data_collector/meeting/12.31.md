# 📅 12.31 Being Geul 프로젝트 팀 회의록

## 1. 📢 주요 결정 사항 (Key Decisions)

### 🛑 유료 회원 및 결제 기능
* **결정:** **유료 결제 기능은 도입하지 않음.** (개발 일정 및 포트폴리오 목적상 불필요)
* **변경:** '유료/무료' 구분이 아닌 **'비회원/회원'**으로 기능을 차별화함.
* **회원 혜택:** DB 연동을 통한 개인화 서비스(찜하기, 추천 정책, 마감 알림 등) 제공을 강조하여 회원가입 유도.

### 🎨 디자인 및 UI
* **카테고리별 컬러 코딩:** 정책 카드의 배경색과 폰트 색상을 각 카테고리(취업, 주거, 금융 등)를 상징하는 **'옷 색깔'** 코드에 맞춰 통일하기로 함. (연한 톤으로 조정 필요)
* **알림 기능 (말풍선):** 별도의 모달 창 대신, 내비게이션 바(Nav)에 **'말풍선(Speech Bubble)'**이나 **'빨간 점(Badge)'** 형태의 시각적 알림을 추가하여 마감 임박 정책 등을 알림. (캐릭터 펭이가 "할 말 있어!" 하는 느낌)

### 🐙 Git 협업 방식 (Branch 전략)
* **작업 방식:** 팀원들은 각자 본인 이름(예: `jisang`)으로 **브랜치(Branch)**를 생성하여 작업.
* **절차:**
    1.  VS Code(Cursor)의 **Source Control** 탭 사용.
    2.  `Create Branch` → 본인 이름 입력.
    3.  작업 후 `Commit` 및 `Publish/Sync Changes` 버튼 클릭.
    4.  **Merge(병합)**는 충돌 방지를 위해 팀장(다인)이 일괄 확인 후 진행.
* **참고:** 브랜치는 작업 후 삭제하지 않고 계속 유지하며 진행.
