#### 1217 Prompt [청년센터와 콘텐츠의 api를 써도 호출이 안됨, 청년정책만 가져오는 걸로 다시 변경]

```

청년정책 API (`getPlcy`)를 호출하여 총 4,000건의 데이터를 수집하고, **각 데이터 특성에 맞는 개별 로직**을 적용해 Python 코드를 실행해.

[1. API 호출 정보]
1. **정책**: `https://www.youthcenter.go.kr/go/ythip/getPlcy`



**[공통 파라미터]**
- `apiKeyNm`: (.env의 youth_api 사용)
- `pageSize`: 4000
- `pageNum`: 1
- `pageType`: 2
- 'display' : 4000

[2. Python 데이터 처리 지침 (URL별 분기 처리)]
API 응답(`items`)을 순회할 때, 현재 처리 중인 URL이 무엇인지에 따라 아래 로직 적용

---
**(A) 정책 API (`getPlcy`) 처리 로직**
1. **필드 매핑**: 제목=`plcyNm`, 내용=`plcyExplnCn`
2. **날짜 필터링 (엄격)**:
   - `bizPrdEndYmd`(종료일) 또는 `bizPrdEtcCn`(신청기간) 확인.
   - 종료일 또는 신청기간의 마지막 날짜가 오늘 날짜(Current Date)보다 과거면 **삭제(Drop)**.
3. **링크 추출**: `refUrlAddr2` -> `refUrlAddr1` -> `aplyUrlAddr` 순서.
4. **지역**: `rgtrInstCdNm` 분석.




---

[3. 공통 가공 및 출력]
모든 데이터는 아래 JSON 포맷으로 통일하되, 빈 값은 채워넣어.
link항목엔 무조건 엄격하게 검증하여 유효한 링크여야한다. 링크를 들어갔을 때 없거나, 혹은 메인페이지로 리다이렉팅 되는 링크는 Drop
period 가 상시, 분기별 모집, 매년 모집, ... 등등 이런식으로 적혀있는건 그대로 작성한다. 대신 날짜가 나와있다면 날짜를 작성.
South Korea 시간 기준으로 오늘 날짜 이전에 마감된 데이터는 drop. period를 고려하여 유효한 데이터여야 한다.
main.py 과 being_final은 건드리지 않는다. polices.json과 그 파일을 반영한 being_test만 수정.
온통청년에서 정책 상세페이지를 보는 웹페이지 주소는 https://www.youthcenter.go.kr/youthPolicy/ythPlcyDetail.do?bizId=20250904005400211625 이게 아니라 https://www.youthcenter.go.kr/youthPolicy/ythPlcyTotalSearch/ythPlcyDetail/20250619005400111071?isNew=N 이런식이야.

3. **지역(Location) 매핑**:static
   - `rgtrInstCdNm`(등록기관명) 값을 확인해. (예: "전라남도", "서울시")
   - 이 값을 기반으로 [서울, 경기, 인천, 부산, 대구, 광주, 대전, 울산, 세종, 강원, 충북, 충남, 전북, 전남, 경북, 경남, 제주, 전국] 중 하나로 분류해.
   - 지역을 나눌 때 전국 이라는 지역이라면, 여러 지역으로 나눠서 같은 내용 적지말고, 전국 하나로 놓고 정책 하나만 쓸것

4. **장르(Genre) 분류**:
   - 정책명(`plcyNm`)과 내용(`plcyExplnCn`)을 분석하여 [취업/직무, 창업/사업, 주거/자립, 금융/생활비, 교육/자격증, 복지/문화] 중 하나로 분류.
   - 장르 분류 참고: 1. 취업/직무 (Employee)
"남의 회사에 들어가기 위한 모든 것"
핵심 기준: 회사에 고용되기 위해 필요한 지원.
포함: 면접 정장 대여, 면접 수당, 취업 성공 패키지, 인턴십, 일경험 프로그램, 자기소개서 컨설팅.
제외: 창업 관련 멘토링, 자격증 시험료(교육으로 분류).
2. 창업/사업 (Employer)
"내 사업을 하기 위한 모든 것 (돈+공간+교육)"
핵심 기준: 사업자등록증이 필요하거나 예비 사장님을 위한 지원. (여기가 핵심! 돈, 공간, 멘토링을 다 흡수함)
포함: 사업화 자금(융자/지원금), 창업 보육 센터(사무실), 창업 멘토링, 시제품 제작, 마케팅 지원.
제외: 개인적인 비상금 대출(금융), 전세 대출(주거).
3. 주거/자립 (Housing)
"먹고 자는 '집'과 관련된 모든 것"
핵심 기준: 물리적인 '집' 공간과 그 집을 구하기 위한 돈.
포함: 행복주택, 청년안심주택, 기숙사, 전세/월세 보증금 대출, 월세 지원, 이사비 지원, 중개수수료.
제외: 사무실 임대(창업), 학자금 대출(금융).
4. 금융/생활비 (Personal Finance)
"개인의 지갑을 채워주는 순수 현금/자산"
핵심 기준: 집이나 사업 목적이 아닌, 개인의 자산 형성이나 긴급 생활비.
포함: 청년도약계좌, 내일저축계좌, 학자금 대출(이자지원), 비상금 대출, 신용회복 지원, 군장병 적금.
제외: 사업 자금 대출(창업), 전세 자금 대출(주거).
5. 교육/자격증 (Growth)
"나의 스펙(Spec)을 쌓는 일반적인 공부"
핵심 기준: 특정 회사가 아닌, 나 자신의 역량을 키우는 공부.
포함: 내일배움카드, 국가기술자격증 응시료 지원, 토익/어학 수강료, 디지털/코딩 교육, 평생교육 바우처.
제외: 창업 멘토링(창업), 취업 면접 특강(취업).
6. 복지/문화 (Well-being)
"몸과 마음의 건강, 그리고 노는 것"
핵심 기준: 일/공부/집을 떠나 삶의 질을 높이는 지원 + 사회 참여.
포함: 건강검진, 심리상담(마음건강), 문화예술 패스, K-패스(교통비), 식비(천원의 아침밥), 동아리/네트워킹, 서포터즈.
