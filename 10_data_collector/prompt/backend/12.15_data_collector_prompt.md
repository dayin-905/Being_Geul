[2. Python 데이터 처리 지침 (URL별 분기 처리)]
API 응답(`items`)을 순회할 때, 현재 처리 중인 URL이 무엇인지에 따라 아래 **(A), (B), (C) 로직을 다르게 적용**할 것.

---
**(A) 정책 API (`getPlcy`) 처리 로직**
1. **필드 매핑**: 제목=`plcyNm`, 내용=`plcyExplnCn`
2. **날짜 필터링 (엄격)**:
   - `bizPrdEndYmd`(종료일) 또는 `rqutPrdCn`(신청기간) 확인.
   - 오늘 날짜(Current Date)보다 과거면 **삭제(Drop)**.
3. **링크 추출**: `refUrlAddr2` -> `aplyUrlAddr` -> `refUrlAddr1` 순서.
4. **지역**: `rgtrInstCdNm` 분석.

---
**(B) 공간 API (`getSpace` / `getYthSps`) 처리 로직**
1. **필드 매핑**: 제목=`spcName`, 내용=`addr` + `operTime`
2. **날짜 필터링 (미적용)**:
   - **경고: 공간 정보에는 마감일이 없다.** 날짜 필터링을 절대 수행하지 말고 무조건 수집해.
3. **링크 추출**: `hmpgUrlAddr` 필드가 있으면 사용, 없으면 지도검색 링크 생성.
4. **지역**: `addr`(주소) 필드를 분석하여 지역 매핑. (예: "서울 마포구..." -> 서울)

---
**(C) 뉴스/컨텐츠 API (`getContent` / `getEmplymNews`) 처리 로직**
1. **필드 매핑**: 제목=`sjnm`, 내용=`dtsCn`
2. **날짜 필터링 (완화)**:
   - `regDt`(등록일)만 존재하므로 필터링하지 말고 최신순 정렬만 수행.
3. **링크 추출**: `url` 필드 확인.
