[핵심 지침]
API가 주는 Raw Data(JSON)에는 이미 완벽한 링크가 존재한다. AI가 임의로 링크를 생성하거나 조립하지 말고, **아래 지정된 필드값을 그대로 추출(Extract)**하는 것에 집중해.

[1. Python 필터링 및 데이터 추출 로직]
API 응답 리스트(`items`)를 순회하며 다음 로직을 수행해:

1. **유효 기간 검증 (날짜 필터링)**:
    JSON의 `bizPrdEndYmd`(사업종료일) 또는 `rqutPrdCn`(신청기간) 값을 확인.
   - 오늘 날짜 기준으로 현재 시행중이거나, 혹은 시행 예정인 데이터만 남겨.
   - 값의 형식이 'YYYYMMDD'(`20261231`)라면 날짜로 변환하여 **오늘 날짜보다 미래인 경우(진행중)**만 남겨.
   - 날짜가 과거라면 과감히 리스트에서 삭제(Drop).
   

2. **🔗 링크(Link) 추출 우선순위 (절대 규칙)**:
   - AI가 URL을 만들지 말고, JSON의 아래 필드 값을 순서대로 확인하여 **값이 있는 경우 그대로 가져올 것.**
   - **제 1순위**: `refUrlAddr2` (여기에 값이 있으면 무조건 이것을 사용. *가장 중요*)
   - **제 2순위**: `etctMttrCn` (URL이 포함되어 있다면 추출)
   - **제 3순위**: `refUrlAddr1` (위 1,2번이 비어있을 때만 사용)
   - **제 4순위**: `onlinescrtyUrlAddr` (온라인 신청 주소)
   
   *(경고: 위 필드들이 모두 비어있을 경우에만 최후의 수단으로 `bizId`를 이용해 URL 조립을 시도할 것.)*
