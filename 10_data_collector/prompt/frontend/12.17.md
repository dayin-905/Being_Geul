**날짜:** 2025. 12. 17  
**작업 범위:** `main.html` GSAP 충돌 해결 ~ Apple Style Banner 고도화

## 1. 🛠️ GSAP 충돌 및 애니메이션 로직 개선

### 🚨 문제 상황 (Issue)
1.  **애니메이션 중복 실행:** `script.js`에 작성된 `gsap.from()` 코드가 페이지 로드 시 자동으로 실행되면서, `main.html`에서 제어하려는 타이밍과 충돌 발생 (화면 깜빡임, 두 번 실행됨).
2.  **Lottie 로딩 대기:** 로띠 애니메이션이 로드되지 않거나 에러가 났을 때, 프리로더가 사라지지 않고 무한 대기하는 현상 발생.
3.  **FOUC (Flash of Unstyled Content):** 프리로더가 사라지는 순간, 텍스트가 잠깐 보였다가 다시 애니메이션 시작 위치로 이동하는 깜빡임 현상.

### ✅ 해결 방안 (Solution)
* **`script.js` 구조 변경:**
    * 자동 실행 코드를 모두 삭제.
    * `initHeaderAnimation()`: 초기 상태를 `opacity: 0`, `y: 50`으로 강제 설정하는 함수 추가 (프리로더 뒤에서 실행).
    * `playHeaderAnimation()`: 실제 등장을 담당하는 함수 (`to()` 사용)로 분리.
* **Lottie 에러 방어:** `data_failed`, `error` 이벤트 리스너를 추가하여 로띠 로드 실패 시 즉시 프리로더를 제거하고 본문을 보여주도록 수정.
* **실행 순서 확립:** `init(숨김)` → `Preloader FadeOut` → `play(등장)` 순서로 로직 정리.

## 2. 📐 레이아웃 시프트(Layout Shift) 방지

### 🚨 문제 상황
* 동영상과 헤더 텍스트가 로드되기 전에는 높이값이 0이었다가, 로드되는 순간 공간을 차지하면서 전체 레이아웃이 덜컥거림.

### ✅ 해결 방안
* **텍스트 영역:** CSS `min-height: 180px`을 주어 텍스트가 없어도 공간을 미리 확보.
* **비디오 영역:** `.header-image-container`에 `aspect-ratio: 16 / 9`와 `min-height`를 적용하여 비디오 로딩 전에도 빈 박스 형태 유지.

## 3. 🔧 서브 페이지 (MyPage) 복구

### 🚨 문제 상황
* `script.js`의 자동 실행 코드를 삭제하면서 `mypage.html`의 헤더 애니메이션이 작동하지 않음.
* "My Analytics" 버튼이 Flexbox 속성 때문에 가로로 길게 늘어짐.

### ✅ 해결 방안
* **애니메이션 연결:** `mypage.html` 하단 스크립트에 `window.playHeaderAnimation()` 호출 로직 추가.
* **CSS 초기화:** `<head>`에 초기 숨김 처리 스타일 추가.
* **레이아웃 수정:** `.header-text`에 `items-center` (모바일), `md:items-start` (PC) 클래스를 추가하여 버튼 늘어짐 방지.

## 4. 🎨 UX/UI 리뉴얼: Search Section → Apple Style Banner

### 💡 기획 의도
* 기존의 `Search Section`은 기능이 중복되고 시각적 피로도가 높음.
* 사용자 맞춤형 대시보드 성격을 강화하기 위해 **탐색(Discovery)을 유도하는 섹션**으로 변경.

### 🔄 디자인 변천사
1.  **Trend Keywords:** 단순 해시태그 나열 (기각 - `all.html` 성격에 더 가까움).
2.  **Category Quick Access:** 7개 키워드 필터 버튼 모음.
3.  **Apple Style Banner (최종):** 섹션을 시각적으로 구분 짓는 **'띠(Strip)'** 형태의 배너.

### ✨ 최종 구현 내용 (Apple Style Banner)
* **반응형 형태 변형:**
    * **모바일:** 넉넉한 여백의 **카드(Card)** 형태.
    * **PC/태블릿:** 얇고 긴 **바(Bar)** 형태로 섹션을 가로지르는 구분선 역할.
* **디자인 톤앤매너:**
    * **Warm Dark:** 완전한 블랙 대신 `#222222` (Warm Dark Gray) 배경 사용.
    * **Minimal:** 네온 글로우 제거, 매트한 질감의 아이콘 배경.
    * **Brand Color:** 아이콘 색상을 사이트 테마(`Orange`, `Teal`, `Beige`)와 통일.
* **인터랙션 기능:**
    * **순환 애니메이션:** GSAP Timeline을 사용하여 아이콘과 텍스트가 동시에 교체됨.
    * **동적 텍스트:** "취업/창업을", "주거 지원을" 등 조사까지 포함하여 자연스럽게 문구 변경.
    * **텍스트 컬러:** 강조 키워드에 `text-primary-orange` 적용.
