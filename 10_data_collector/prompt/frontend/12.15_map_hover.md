# 쓱쓱 프로젝트 프론트엔드 개발 작업 로그  인터랙티브 지도 구현 (Landing Page)

작업 개요 `landing.html` 내 GSAP 및 SVG를 활용한 반응형 지도 UI 구현 및 사용자 시나리오(UX)에 따른 인터랙션 로직 고도화
기술 스택 FastAPI, Jinja2 Template, Vanilla JS, Tailwind CSS, GSAP
작업자 쓱쓱 프로젝트 풀스택 개발자 (with AI Assistant)

---

## 📅 Phase 1 지도 데이터 전략 수립 및 초기 구조화

### 1. 세부 지역 지도(SVG) 생성 전략 수립
요청 내용 (Prompt)
 기존 전국 지도(`map.svg`) 외에 17개 시도의 세부 지역(구군 단위) 지도를 작업해야 함. 일일이 그리는 대신, 개발자스럽고 효율적으로 SVG를 생성하고 관리하는 방법 제안 요청.

해결 방안 (Solution)
 Data-Driven Approach 일러스트레이터 수작업 대신, GIS 오픈 데이터(GeoJSON) 활용 제안.
 Tooling Mapshaper를 활용하여 행정구역 데이터 필터링 및 SVG 변환경량화 프로세스 확립.
 Architecture FastAPI 라우터를 통해 URL 파라미터에 따라 SVG를 동적으로 서빙하는 구조 설계.

### 2. 상세 페이지 연결 및 DOM 구조 통일
요청 내용 (Prompt)
 `landing.html`의 전국 지도 클릭 시, 해당 지역의 상세 지도(`total_.svg`)로 연결되는 구조 제작 요청. 기존 애니메이션 효과 유지를 위해 DOM 구조 통일성 확보 필요.

해결 방안 (Solution)
 SPA(Single Page Application) UX 페이지 새로고침 없이 URL 파라미터(`region=xxx`) 변경만으로 전국 지도 ↔ 상세 지도를 교체하는 JS 로직 구현.
 Data Structure `REGION_DATA` 객체를 정의하여 전국 및 각 상세 지역의 메타데이터(파일 경로, 지역명, 데이터 개수 등) 통합 관리.

## 📅 Phase 2 트러블 슈팅 및 로직 정교화

### 3. SVG ID 매핑 오류 디버깅 (Gray Map Issue)
요청 내용 (Prompt)
 지도는 로드되지만, 클릭이 안 되고 회색(비활성)으로만 나오는 오류 발생. 원인 파악 및 단계별 해결 계획 수립 요청.

해결 방안 (Solution)
 Diagnosis JS 코드는 그룹(`g`) 태그를 찾는데, 실제 SVG는 패스(`path`)에 ID가 부여되어 매칭 실패.
 Refactoring `initMapEvents` 함수를 강화하여 `g`와 `path`를 모두 탐색하도록 수정하고, 디버깅용 로그(`console.log`) 추가하여 매핑 상태 검증 완료.

### 4. SVG 파일별 상이한 ID 구조 통합 처리
요청 내용 (Prompt)
 `map.svg`(전국)와 `total_.svg`(상세)의 내부 ID 네이밍 규칙이 다름 (예 `_st` 접미사 유무, 그룹 ID 등). 이를 모두 수용하는 로직 수정 요청.

해결 방안 (Solution)
 Logic Branching `isDetailMode` 플래그를 활용하여 전국 모드일 때와 상세 모드일 때의 ID 파싱 로직 분리.
 Exception Handling 부모 그룹 ID(`total_...`) 등 불필요한 요소는 이벤트 바인딩에서 제외하여 오작동 방지.

## 📅 Phase 3 UX 스토리텔링 및 시나리오 구현

### 5. 사용자 시나리오(Case 1 vs Case 2) 분기 처리
요청 내용 (Prompt)
 지역별 데이터 유무에 따른 이동 로직 분리.
  Case 1 (상세 지도 없음) 클릭 시 바로 메인 페이지(`main.html`)로 이동.
  Case 2 (상세 지도 있음) 상세 지도로 줌인 후, 세부 지역 클릭 시 메인 페이지로 이동.

해결 방안 (Solution)
 Navigation Logic `REGION_DATA` 내 상세 DB 존재 여부를 확인하여, 클릭 이벤트 발생 시 페이지 이동(`window.location.href`)과 뷰 변경(`window.location.search`)을 동적으로 결정하는 알고리즘 구현.

### 6. 인트로(Intro-gate) 및 SVG 사이즈 최적화
요청 내용 (Prompt)
 전국지도 보기를 한 번 클릭한 고객에게는 인트로 화면을 다시 띄우지 않도록 수정. 또한, 상세 지도가 화면을 벗어나는 사이즈 오류 해결 요청.

해결 방안 (Solution)
 Session Storage `sessionStorage`를 활용하여 방문 기록을 체크, 재방문 시 인트로 자동 스킵 구현.
 CSSJS Override SVG 파일 자체의 고정 `widthheight` 속성을 JS로 제거하고 CSS로 제어하여 반응형 레이아웃 완벽 대응.

## 📅 Phase 4 회원 유치 전략(Conversion) UI 구현

### 7. 탐색(Discovery) vs 귀환(Return) UX 구현
요청 내용 (Prompt)
 신규 회원에게는 탐색 경험을, 기존 회원에게는 빠른 이동 경험을 제공하는 UX 시나리오 적용. 로그인 모달 및 Fast-Track 애니메이션 구현 요청.

해결 방안 (Solution)
 Contextual Modal 비로그인 사용자가 지역 클릭 시 이 지역 소식을 받아보시겠습니까라는 가입 유도 모달 트리거.
 Fast-Track Effect 로그인 성공 시, 인트로 없이 설정된 '나의 지역'으로 카메라가 줌인되며 이동하는 GSAP 애니메이션 구현.

### 8. 로그인 모달 디자인 및 뷰 스위칭 (최종)
요청 내용 (Prompt)
 쓱쓱 프로젝트의 톤앤매너(Teal 컬러, 둥근 모서리 등)를 유지하며, 프로모션 뷰와 로그인 폼 뷰가 부드럽게 전환되는 모달 UI 제작 요청. (DB 연동 전 단계)

해결 방안 (Solution)
 UI Design Tailwind CSS를 활용한 모던한 카드 형태의 모달 디자인.
 View Switching 하나의 모달 내에서 '가입 권유 화면' ↔ '로그인 입력 화면'이 즉시 전환되는 JS 로직 구현.
 Interaction '둘러보기' 클릭 시 비로그인 상태로 메인 페이지 이동 기능 추가.
